# 前端功能与交互

## 模块定位

`stock-frontend` 是独立 React、TypeScript 和 Vite Maven 模块，提供数据观察、模型运维、策略配置、任务管理、交易查询和系统设置界面。

生产环境由独立 Nginx 容器托管静态资源，不再打入 Backend JAR。开发环境通过 Vite 代理分别访问 Backend 和 Agent。

## 主要页面

| 路由 | 功能 |
|---|---|
| `/login` | 系统用户登录 |
| `/dashboard` | 系统概览和关键状态 |
| `/market` | 市场行情和统计 |
| `/stockInformation` | 股票资料和历史数据 |
| `/historyOrders` | 券商历史订单 |
| `/tradeRecords` | 已聚合交易记录和收益 |
| `/logs` | Backend 实时日志 |
| `/modelOperations` | 模型训练、版本、预测和评估 |
| `/sentimentModel` | 情感模型状态和分析 |
| `/strategyConfig` | 策略、真实交易和 Agent 决策配置 |
| `/jobs` | Quartz 任务管理与执行历史 |
| `/settings` | 用户与系统设置 |

## 接口分流

| 请求 | 开发代理 | 生产 Nginx |
|---|---|---|
| `/api/agent/**` | `localhost:8081` | `stock-agent:8081` |
| 其他 `/api/**` | `localhost:8080` | `stock-backend:8080` |
| `/ws/**` | `localhost:8080` | `stock-backend:8080` |
| `/api/internal/**` | 不允许浏览器调用 | 直接返回 404 |

Backend 与 Agent 通过 Redis 共享服务端 Session，因此浏览器只维护一套登录 Cookie。内部服务令牌不得发送到浏览器。

## 实现与契约

React Router 负责页面路由，Zustand 管理跨页面状态，Axios 封装 HTTP 请求，Ant Design 与 TailwindCSS 实现界面。接口统一读取 `ResponseDTO<T>`，页面类型必须与后端 DTO 对齐，不使用 `any` 掩盖契约变化。

加载、空数据、失败和禁用状态分别展示。Mock 数据只能作为明确的展示兜底，不能伪装为真实结果。页面按钮状态不能替代 Backend 的权限、风险和交易校验。

## 构建与部署

- Maven 的 `frontend-maven-plugin` 安装固定 Node/npm、执行 `npm ci` 和 `npm run build`。
- Docker 多阶段构建将 `dist/` 复制到 Nginx 镜像。
- Frontend 使用 `frontend-vX.Y[.Z]` 标签独立构建和发布。
- Frontend 发布不重建 Backend 或 Agent 容器。
