# 训练推理与模型生命周期

## 训练数据快照

训练前先创建数据快照，记录股票范围、日期范围、样本数量、特征版本、文件信息和校验值。快照用于确保训练输入可复核，并将数据准备失败与模型训练失败区分开。

样本按股票时间序列生成，训练集和验证集按时间切分并保留间隔，避免随机切分造成未来数据泄漏。

## LSTM 模型

LSTM 面向多股票共享预测，输入包括历史价格序列、技术特征、股票或行业标识以及市场参考序列。输出用于描述方向、收益和下行风险等预测信息。

训练过程受以下门禁约束：

- 训练数据股票数和覆盖率达到最低要求。
- 参数在允许范围内。
- 同一时间只允许受控数量的训练任务。
- 交易关键时间窗口不执行高资源训练。
- 训练异常不影响当前激活模型。

## 情感模型

财经情感模型从 `model-artifacts/sentiment` 加载固定 Hugging Face PyTorch 制品，输出正向、中性和负向分类及相关分值。

情感聚合同时考虑新闻时间、来源、事件类型和否定语义。关键词只能作为辅助特征，不能在中性模型分数下单独触发强风险结论。

## 预测批次

每日预测以批次为单位：

1. 确认目标交易日和行情覆盖。
2. 解析当前激活模型。
3. 筛选满足历史长度和质量要求的股票。
4. 逐股票推理并保存结果。
5. 汇总成功、跳过和失败数量。
6. 将批次状态提供给策略和 Agent 使用。

跳过表示数据或业务条件不满足，失败表示执行异常，两者不能混为同一状态。

## 模型生命周期

```text
训练数据快照
  → 训练运行
  → 候选模型
  → 评估与人工确认
  → 激活模型
  → 在线推理
  → 效果评估
  → 保持、切换或回滚
```

激活记录维护当前版本、上一版本和操作审计。回滚恢复的是完整模型版本关系，而不是简单替换一个文件路径。

## 评估原则

- 方向准确率、收益误差和覆盖率分别统计。
- 评估使用预测产生之后的真实行情。
- 交易成本、最小佣金和滑点需要纳入可交易性分析。
- 评估结果用于模型选择和策略输入，不直接触发真实委托。
