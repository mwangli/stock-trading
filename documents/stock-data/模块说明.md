# stock-data 领域说明

## 领域定位

`com.stock.data` 是 `stock-backend` 内部的事实数据领域，负责股票资料、行情、新闻、交易日历、复权和可交易状态的采集、标准化、增量持久化与查询，不是独立 Maven 模块。

## 核心能力

| 能力 | 说明 |
|---|---|
| 股票资料 | 全量同步股票代码、名称、市场和上市信息 |
| 日线与分钟线 | 支持日常增量、按时间窗口回补和查询 |
| 交易日历 | 维护开闭市状态、节假日和覆盖范围 |
| 可交易事实 | 保存停牌、涨跌停和开放交易状态 |
| 复权与参考序列 | 为模型和回测提供一致价格基础 |
| 新闻 | 按股票采集、去重、分类并补充事件元数据 |
| 数据质量 | 校验数据范围、完整性、来源状态和异常原因 |

## 实现与存储

Controller 只负责参数、日志和 `ResponseDTO` 封装。`StockListSyncService` 负责股票列表同步，`StockPriceService` 负责日线增量和历史回补，`StockQueryService` 负责查询与统计；新闻采集、文档构造和同步水位由独立服务承担。

股票资料、交易日历、行情、新闻、复权、可交易事实和历史股票池属于增量、时序或大文档数据，统一写入 MongoDB。Redis 只缓存股票资料、最新价格和交易日历等热点查询，写入或清理权威数据时同步失效缓存。

## 协作边界

- `com.stock.model`、`com.stock.strategy` 和 `com.stock.trading` 通过明确 Service/Repository 使用事实数据。
- Agent 只能通过 Backend 的 `/api/internal/agentFacts/**` 获取受控摘要，不直接访问数据领域代码或集合。
- 数据源整体为空、解析失败或关键数据缺失时明确失败，不使用默认值伪装成功。
- 未确认退市的股票不能因本次接口未返回而删除。
- 未确认交易日不能被自动交易链路当作正常交易日。
