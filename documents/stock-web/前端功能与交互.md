# 前端功能与交互

## 模块定位

`stock-web` 是 React、TypeScript 和 Vite 前端模块，提供数据观察、模型运维、策略配置、任务管理、交易查询和系统设置界面。

生产环境中，前端构建结果作为静态资源 JAR 被 `stock-starter` 引入，由 Spring Boot 同源托管。

## 主要页面

| 路由 | 功能 |
|---|---|
| `/login` | 系统用户登录 |
| `/dashboard` | 系统概览和关键状态 |
| `/market` | 市场行情和统计 |
| `/stockInformation` | 股票资料和历史数据 |
| `/historyOrders` | 券商历史订单 |
| `/tradeRecords` | 已聚合交易记录和收益 |
| `/tradeRecordDemos` | 交易记录样例展示 |
| `/logs` | 后端实时日志 |
| `/modelOperations` | 模型训练、版本、预测和评估 |
| `/sentimentModel` | 情感模型状态和分析 |
| `/strategyConfig` | 策略、真实交易和 Agent 决策配置 |
| `/jobs` | Quartz 任务管理与执行历史 |
| `/settings` | 用户与系统设置 |

## 实现方式

React Router 负责页面路由，Zustand 管理跨页面状态，Axios 封装 HTTP 请求，Ant Design 与 TailwindCSS 共同实现界面。日志页面通过 WebSocket 接收服务端广播。

## 接口契约

- 接口统一使用 `/api/` 前缀和 lowerCamelCase 路径。
- 前端按 `ResponseDTO<T>` 读取成功状态、消息和数据。
- 页面类型应与后端 DTO 对齐，不使用 `any` 掩盖契约变化。
- 加载、空数据、失败和禁用状态分别展示。
- Mock 数据只能作为明确的展示兜底，不能伪装为真实结果。

## 交互边界

- 页面按钮是否可点击不能替代后端权限和风控。
- 危险操作需要确认，但最终校验仍由后端完成。
- 状态不可用时保留稳定操作位并禁用，避免表格跳动。
- 页面级内容由统一容器滚动，普通表格不建立重复纵向滚动区。
- 日期范围、分页、状态标签和操作列使用全局一致样式。

## 构建与托管

Maven 在资源生成阶段安装指定 Node/npm、执行 `npm ci` 和 Vite 构建，再将 `dist/` 复制到模块输出的 `static/`。开发期可以单独运行 Vite，但生产部署只有一个应用容器。
