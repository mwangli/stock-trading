# 前端架构

## 模块定位

`stock-frontend` 是独立 React、TypeScript 和 Vite Maven 模块，提供数据观察、模型运维、策略配置、任务管理、交易查询和系统设置界面。生产静态资源由 Nginx 独立托管，不打入 Backend JAR。

## 主要页面

| 路由 | 功能 |
|---|---|
| `/login` | 系统用户登录 |
| `/dashboard` | 系统概览和关键状态 |
| `/market` | 市场行情和统计 |
| `/stockInformation` | 股票资料和历史数据 |
| `/historyOrders` | 券商历史订单 |
| `/tradeRecords` | 聚合交易记录和收益 |
| `/logs` | Backend 实时日志 |
| `/modelOperations` | 模型训练、版本、预测和评估 |
| `/sentimentModel` | 情感模型状态和分析 |
| `/strategyConfig` | 策略、真实交易和 Agent 配置 |
| `/jobs` | Quartz 任务及执行历史 |
| `/settings` | 用户与系统设置 |

## 接口分流

| 请求 | 开发代理 | 生产 Nginx |
|---|---|---|
| `/api/agent/**` | `localhost:8081` | `stock-agent:8081` |
| 其他 `/api/**` | `localhost:8080` | `stock-backend:8080` |
| `/ws/**` | `localhost:8080` | `stock-backend:8080` |
| `/api/internal/**` | 禁止调用 | 返回 404 |

Backend 与 Agent 共享服务端 Redis Session，浏览器只维护登录 Cookie。内部服务令牌不能发送到浏览器。

## 实现契约

React Router 负责路由，Zustand 管理跨页面状态，Axios 封装 HTTP 请求，Ant Design 与 TailwindCSS 构建界面。接口读取 `ResponseDTO<T>`，前端类型与后端 DTO 对齐，不使用 `any` 掩盖契约变化。

页面分别表达加载、空数据、失败和禁用状态。Mock 数据只能作为明确的展示兜底，不能伪装为真实业务结果。按钮状态不替代 Backend 的权限、风险和交易校验。

页面级纵向滚动由布局层统一承担，普通表格只使用必要的横向滚动，避免页面和表格形成双纵向滚动区域。

## 构建与发布

Maven `frontend-maven-plugin` 安装固定 Node/npm，并执行 `npm ci` 与生产构建。Docker 多阶段构建将 `dist/` 复制到 Nginx 镜像。Frontend 使用独立标签和工作流发布，不重建 Backend 或 Agent。
