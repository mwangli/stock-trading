# stock-base 模块说明

## 模块定位

`stock-base` 保存多个业务模块共同依赖、且语义稳定的最小契约。它位于依赖链最底层，目的是降低跨模块协作时的反向依赖和重复定义。

## 业务用途

- 为所有 Controller 提供统一响应结构 `ResponseDTO<T>`。
- 为 Agent 查询任务运行状态提供只读 Port。
- 表达跨模块通用的任务执行摘要和可跳过异常。

## 实现方式

当前模块主要包含：

| 类型 | 用途 |
|---|---|
| `ResponseDTO<T>` | 统一接口成功状态、提示信息和业务数据 |
| `JobExecutionQueryPort` | 在不依赖 `stock-job` 实现的情况下查询任务摘要 |
| `JobExecutionSnapshot` | 表达任务名称、状态和脱敏错误信息 |
| `JobSkippedException` | 表达具备业务原因的安全跳过，而非系统故障 |

`stock-job` 实现任务查询 Port，`stock-agent` 等模块只依赖 Port，因此不会形成 `stock-agent ↔ stock-job` 循环依赖。

## 边界

- 只放稳定、被多个模块使用的契约。
- 不放业务 Entity、Repository、Controller 或具体 Service。
- 不把所有 DTO 都集中到本模块；接口 DTO 仍归属于实际业务模块。
- 新增公共类型前应确认至少存在真实跨模块调用需求。

## 主要代码位置

```text

stock-application/stock-base/src/main/java/com/stock/base/api/ResponseDTO.java
```

`ResponseDTO` 位于 `com.stock.base.api`，作为全部 Controller 共用的唯一外层响应契约。
