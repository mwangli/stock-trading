# stock-base 领域说明

## 领域定位

`com.stock.base` 是 `stock-backend` 内部的最小公共契约区，不是独立 Maven 模块。它只保存 Backend 多个领域共同使用、语义稳定的响应、异常、Port 和内部接口安全配置。

## 当前内容

| 类型 | 用途 |
|---|---|
| `ResponseDTO<T>` | Backend Controller 的统一外层响应 |
| `JobExecutionQueryPort` | Backend 内部查询任务摘要，避免领域实现反向耦合 |
| `TradeDecisionGatePort` | 交易流程调用决策门禁的稳定接口，由 HTTP 适配器实现 |
| `JobSkippedException` | 表达具备业务原因的安全跳过，而非系统故障 |
| `InternalApiProperties` | 读取内部 API 共享令牌配置 |
| `InternalTokenInterceptor` | 校验 Backend 内部接口的 `X-Internal-Token` |

Agent 不依赖这些 Java 类型。Backend 与 Agent 之间使用各自定义的 HTTP DTO 交换结构化数据。

## 边界

- 只放 Backend 内多个领域真实复用的稳定契约。
- 不放业务 Entity、Repository、Controller 或具体 Service。
- 不建立可被 Agent 依赖的公共 JAR；跨服务协作统一走内部 HTTP 契约。
- 新增公共类型前必须确认存在真实调用方，禁止为形式统一增加 Facade 或兼容模型。
