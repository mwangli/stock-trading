# AI-AGENT 智能股票交易系统前端

## 模块定位

`stock-client` 是独立 React、TypeScript 和 Vite 应用，负责展示市场事实、模型排名、交易任务、订单成交、Agent 对话和工程文档。前端不参与 Maven Reactor，也不拥有交易决策权。

## 主要页面

| 路由 | 功能 |
|---|---|
| `/dashboard` | 账户资产和收益统计 |
| `/market` | 行情、股票详情和 K 线 |
| `/modelOperations` | 模型训练、版本、评估以及当日模型排名前三名 |
| `/orderRecords` | 分阶段委托、撤单、部分成交和最终成交事实 |
| `/jobs` | Quartz 任务启停和执行历史，包含上午卖出、下午买入 |
| `/agentConversation` | Agent 对话、研究和诊断 |
| `/docs/*` | 只读工程文档工作台 |

策略菜单和页面已删除。旧 `/adaptiveStrategy` 和 `/realTrading` 仅作为历史浏览地址重定向到 `/modelOperations`，不提供旧能力或旧 API 兼容。

## 模型排名展示

模型页面展示当日预测前三名，包括股票、排名、`effectiveModelScore`、预估净收益、预测批次、模型版本、目标交易日和持仓状态。页面数据来自 Trading 对 Model 权威批次的只读查询，不展示独立策略分数或策略版本。

## 任务与订单展示

任务页面以 `job_config.status` 展示 `realTradingMorningSell` 和 `realTradingAfternoonBuy` 的启停状态。订单页面按券商事实展示提交阶段、委托方式、撤单、部分成交和最终状态，不把接口成功或轮询超时显示为成交。

## 接口和安全边界

所有 `/api/**` 请求统一代理到 Application。前端按钮和路由只表达用户操作，不替代服务端的任务状态、资金、持仓、T+1、订单唯一性和券商终态校验。Session Cookie 由浏览器按服务端策略发送，页面不得保存券商凭据。

## 验证边界

当前仅完成源码和 JSON 静态修改，未执行 npm、TypeScript、Vite 构建、浏览器渲染或交互验证。
