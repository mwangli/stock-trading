# AI-AGENT 智能股票交易系统前端

## 模块定位

`stock-client` 是独立 React、TypeScript 和 Vite 应用，负责展示市场事实、模型排名、交易任务、订单成交、Agent 对话和工程文档。前端不参与 Maven Reactor，也不拥有交易决策权。

## UI 设计基线

前端采用安静、紧凑、面向重复操作的交易终端设计语言。页面优先保证信息扫描、状态比较和操作稳定，不使用营销式大标题、装饰性卡片堆叠或与业务无关的视觉元素。

- 颜色、边框、圆角、阴影、文字层级和交互状态优先复用 `stock-client/src/index.css` 的全局变量与现有组件样式。
- 页面专属布局放在对应页面的 `styles.css`；只有跨页面基础控件和通用状态才能进入全局样式。
- 同类按钮、分页、表格操作、状态标签、拖拽分隔线和空状态在不同页面必须保持相同尺寸、颜色和反馈方式。
- 固定格式控件应声明稳定宽度、最小宽度或网格约束，避免加载、悬停、长文案或状态变化造成布局抖动与内容重叠。
- UI 调整不得绕过接口契约、权限、风控、任务状态和交易执行边界。

## 可调宽面板与拖拽分隔线

主导航侧栏、工程文档工作台左右侧栏以及股票详情抽屉使用同一套纵向拖拽设计。实现可以因布局容器不同而采用 Pointer Events 或 Ant Design `Drawer.resizable`，但最终视觉和状态必须一致。

| 项目 | 统一要求 |
|---|---|
| 拖拽命中区域 | `12px` 透明区域，居中覆盖面板分隔线 |
| 中心指示线 | `2px`，静止状态透明 |
| 悬停与焦点 | `var(--brand)` 指示线，`0 0 0 2px var(--brand-soft)` 光晕 |
| 按住与拖动 | `var(--brand)` 指示线，`0 0 0 3px var(--brand-soft)` 光晕 |
| 鼠标指针 | `col-resize` |
| 触摸行为 | `touch-action: none`，由拖拽实现接管移动 |
| 面板位置 | 命中区域中心与实际分隔线重合，不偏移到单侧内容区 |

### 交互规则

1. 每个可调宽面板必须定义默认宽度、最小宽度和最大宽度，不允许宽度无限缩小或覆盖整个主内容区。
2. 最大宽度同时受视口宽度和主内容最小可用宽度限制；窗口缩小时，当前宽度必须自动收敛到新的有效范围。
3. 拖动期间禁止文本选择，并在结束、取消或组件卸载时恢复页面原有光标、文本选择和指针捕获状态。
4. 关闭详情抽屉后，在当前页面生命周期内保留用户最近一次调整结果；除非产品明确要求跨会话保存，否则不新增持久化配置。
5. 自定义分隔线使用 `role="separator"`、`aria-orientation="vertical"`、`aria-label` 和键盘焦点；支持方向键微调，已有“双击恢复默认”能力应保持一致。
6. Ant Design 抽屉优先使用 `resizable`、`size` 和 `maxSize`，并覆盖与本项目规范冲突的整条背景高亮，不重复实现第二套全局鼠标拖拽监听。

### 样式归属与实现参考

- `.app-sidebar-resize-handle`：主导航侧栏拖拽分隔线，维护于 `stock-client/src/index.css`。
- `.documentation-resize-handle`：工程文档工作台左右侧栏分隔线，维护于 `stock-client/src/pages/documentation/styles.css`。
- `.market-detail-drawer-resize-handle`：行情详情抽屉分隔线，维护于 `stock-client/src/index.css`。

新增同类控件时应复用上述状态值和布局规则。允许因容器方向调整 `left` 或 `right` 定位，但不得自行改变命中宽度、指示线宽度、品牌色、光晕等级或按住状态。

## 主要页面

| 路由 | 功能 |
|---|---|
| `/dashboard` | 账户资产和收益统计 |
| `/market` | 行情、股票详情和 K 线 |
| `/modelOperations` | 模型训练、版本、评估以及当日模型排名前三名 |
| `/orderRecords` | 分阶段委托、撤单、部分成交和最终成交事实 |
| `/jobs` | Quartz 任务启停和执行历史，包含上午卖出、下午买入 |
| `/agentConversation` | Agent 对话、研究和诊断 |
| `/docs/*` | 只读工程文档工作台 |

策略菜单和页面已删除。旧 `/adaptiveStrategy` 和 `/realTrading` 仅作为历史浏览地址重定向到 `/modelOperations`，不提供旧能力或旧 API 兼容。

## 模型排名展示

模型页面展示当日预测前三名，包括股票、排名、`effectiveModelScore`、预估净收益、预测批次、模型版本、目标交易日和持仓状态。页面数据来自 Trading 对 Model 权威批次的只读查询，不展示独立策略分数或策略版本。

## 任务与订单展示

任务页面以 `job_config.status` 展示 `realTradingMorningSell` 和 `realTradingAfternoonBuy` 的启停状态。订单页面按券商事实展示提交阶段、委托方式、撤单、部分成交和最终状态，不把接口成功或轮询超时显示为成交。

## 接口和安全边界

所有 `/api/**` 请求统一代理到 Application。前端按钮和路由只表达用户操作，不替代服务端的任务状态、资金、持仓、T+1、订单唯一性和券商终态校验。Session Cookie 由浏览器按服务端策略发送，页面不得保存券商凭据。

## 验证边界

当前前端设计和可调宽控件为 `SOURCE_IMPLEMENTED`。静态检查只能确认源码、样式、文档元数据和引用关系，不能证明浏览器中的拖拽手感、响应式布局或触摸交互。未执行 npm、TypeScript、Vite 构建、浏览器渲染或交互验证。
