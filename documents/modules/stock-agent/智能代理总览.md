# stock-agent 模块说明

## 模块定位

`stock-agent` 是 Application 内的普通 Maven JAR，负责自然语言交互、RAG、Memory、研究诊断和受控只读工具。它不拥有策略状态、交易门禁或券商写权限，也不参与自动交易候选选择。

## 当前业务工具

Agent 通过 Platform 公开 Service 查询：

- 当日模型排名、预测批次、模型版本、有效模型得分和预估净收益。
- 上午卖出和下午买入任务的配置、启停和执行记录。
- 当日券商委托、撤单、部分成交和最终成交。
- 账户、持仓和绩效的脱敏摘要。
- Provider、模型和数据任务诊断。

已删除策略状态、自适应策略、策略版本、系统运行门禁和交易执行门禁工具。工具实现只能调用已有领域 Service，不直接访问 Repository、SQL、Mongo 查询或券商适配器。

## 调用边界

```text
Agent Tool
→ AgentFactQueryService
→ stock-platform 公开 Service
→ Model / Trading 领域 Service
→ 类型化只读 DTO
```

事实不可用时返回明确不可用状态，不使用 Mock、空对象或模型猜测替代。Agent 输出是研究和诊断信息，不控制 `job_config.status`，不提交、撤销或放行真实订单。

## 数据所有权

| 数据 | 权威所有者 | Agent 用途 |
|---|---|---|
| 模型预测批次和排名 | Model | 只读 Evidence |
| 交易任务和执行记录 | Platform | 只读诊断 |
| 账户、持仓、订单、成交和绩效 | Trading | 只读脱敏事实 |
| 会话、任务、Memory、RAG 和审计 | Agent | 用户交互和可追溯记录 |

## 运行与降级

Provider 故障只影响 Agent 生成，不改变自动交易任务状态。Backend 事实读取失败时，相关工具明确失败；Embedding 故障只影响 RAG 和向量 Memory。Agent 不持有券商凭据，不能绕过单一活动买单和撤单终态规则。

## 验证边界

当前仅完成源码静态收敛，未执行 Maven 编译、Spring 装配、LangChain4j 工具发现、模型调用或数据库验证。
