# Stock Backend 整体架构

## 七个 Maven 子模块

```text
stock-server/
├── stock-base/         # 最小公共契约
├── stock-data/         # 市场事实与数据质量
├── stock-model/        # 训练、推理、融合与排名
├── stock-trading/      # 分阶段交易、券商事实与绩效
├── stock-platform/     # Quartz、任务控制与执行审计
├── stock-agent/        # LangChain4j、RAG、Memory 与只读工具
└── stock-application/  # 唯一 Spring Boot 组合根
```

固定依赖方向：

```text
stock-base → stock-data → stock-model → stock-trading
           → stock-platform → stock-agent → stock-application
```

上层模块只能调用下层模块公开 Service 和 DTO，不跨模块访问 Repository 或 Entity，不建立反向依赖或循环依赖。

## 模块职责

| 模块 | 权威职责 | 不负责 |
|---|---|---|
| [stock-base](./stock-base/公共契约.md) | 最小稳定公共契约 | 业务实现和持久化 |
| [stock-data](./stock-data/市场事实.md) | 市场事实采集、标准化、持久化和质量治理 | 模型排名和真实委托 |
| [stock-model](./stock-model/模型模块.md) | 训练快照、模型训练、推理、评估、融合和当日排名 | 券商执行 |
| [stock-trading](./stock-trading/交易执行.md) | 分阶段卖出、前三名买入竞争、订单成交同步和绩效 | 模型训练和二次候选评分 |
| [stock-platform](./stock-platform/任务调度.md) | Quartz 触发、任务启停、执行记录和跨模块只读事实 | 交易算法和券商协议 |
| [stock-agent](./stock-agent/智能代理总览.md) | 对话、RAG、Memory、模型排名和交易事实只读查询 | 下单和交易放行 |
| [stock-application](./stock-application/应用装配.md) | Spring 装配、存储配置和唯一启动入口 | 领域算法 |

## 权威数据流

```text
市场事实
→ 模型预测批次与 effectiveModelScore 排名
→ 上午分阶段卖出
→ 下午前三名竞争唯一资金执行权
→ 券商委托、成交和持仓事实
→ 收益回写
```

Model 的预测批次、模型版本、目标交易日和排名结果是候选权威来源。Trading 不持久化另一套策略候选，不执行技术指标、策略模式或止损止盈二次决策。

## 交易执行不变量

- 每只股票同一时间最多一笔活动卖单。
- 全账户同一时间最多一笔活动买单。
- 买单部分成交后锁定股票，其他候选停止竞争。
- 撤单未确认终态时不释放资金执行权。
- 券商不支持最优五档委托时，卖出使用买五、买入使用卖五作为保护限价。
- 任务关闭只阻止新委托，并撤销当前活动委托；历史订单和成交事实不得删除。

## 数据所有权

| 数据 | 权威模块 | 主要存储 |
|---|---|---|
| 股票、行情、新闻、交易日历 | `stock-data` | MySQL / MongoDB |
| 模型、训练快照、预测批次和排名 | `stock-model` | MySQL / MongoDB / GridFS |
| 账户、持仓、订单、成交和绩效 | `stock-trading` | MySQL / MongoDB |
| 任务配置和执行记录 | `stock-platform` | MySQL / Quartz RAMJobStore |
| Agent 会话、任务、Memory、RAG 和审计 | `stock-agent` | MongoDB |

## 组合根与调度

`com.stock.StockBackendApplication` 是唯一启动类。所有后台任务通过 `JobConfig + JobSchedulerService` 注册，业务类不得新增 `@Scheduled`。Quartz Job 只负责触发和审计，真实业务规则由所属模块 Service 执行。

## 验证边界

当前状态为源码实现。Maven 编译、Spring 装配、数据库基线、Quartz 运行、券商协议字段和真实交易结果不由静态文档证明。
