# 模块依赖与边界

## Maven 结构

根 `pom.xml` 同时承担父 POM 和聚合入口，只注册三个模块：

```text
stock-trading4/
├── stock-backend
├── stock-agent
└── stock-frontend
```

三个模块不通过复制源码或兼容模块共享实现。`stock-agent` 不依赖 `stock-backend`，`stock-frontend` 不进入 Backend JAR。

## Backend 内部边界

`stock-backend` 使用 Java 包和子目录表达领域边界：

| 包根 | 职责 |
|---|---|
| `com.stock.base` | Backend 内部共享响应、异常和最小契约 |
| `com.stock.data` | 股票、行情、新闻、交易日历和数据质量 |
| `com.stock.model` | 训练、推理、模型版本、预测和评估 |
| `com.stock.strategy` | 确定性排名、信号、配置和回测 |
| `com.stock.trading` | 用户、账户、持仓、订单、风控和券商执行 |
| `com.stock.job` | Quartz 注册、运行记录和跨领域编排 |
| `com.stock.backend` | 启动类、持久化配置、缓存、内部 API 和应用装配 |

这些包不是 Maven 子模块。领域内部继续按 `controller`、`service`、`repository`、`entity`、`dto`、`vo`、`config` 等职责分包。

## 运行时依赖

```text
stock-frontend --公开 HTTP/WS--> stock-backend
stock-frontend --公开 HTTP----> stock-agent
stock-agent    --内部事实 API-> stock-backend
stock-backend  --内部门禁 API-> stock-agent
```

- Frontend 的 `/api/agent/**` 由 Nginx 转发至 Agent，其他 `/api/**` 和 `/ws/**` 转发至 Backend。
- Agent 只能通过受保护的 Backend 内部事实 API 获取价格、日历、策略、预测、券商和任务摘要，不直接连接 Backend Repository。
- Backend 调用 Agent 交易判断门禁；调用失败、超时或结果无效时回退 Java 基线，不能扩大候选。
- Backend 与 Agent 使用 Redis 共享登录 Session；内部 API 使用独立 `X-Internal-Token`，不复用用户 Cookie 作为服务身份。

## 数据所有权

| 数据类别 | 权威存储 | 主要所有者 |
|---|---|---|
| 用户、配置、任务、模型元数据、交易批次与状态 | MySQL | Backend |
| 行情、新闻、预测明细、回测和快照 | MongoDB | Backend |
| Agent 会话、任务、Memory、RAG、计划和判断审计 | MongoDB | Agent |
| 登录 Session、查询缓存 | Redis | Backend/Agent 共享基础设施 |
| LSTM 二进制和训练快照 | MongoDB GridFS | Backend |
| Embedding 固定制品 | `model-artifacts/embedding` | Agent |
| Sentiment 固定制品 | `model-artifacts/sentiment` | Backend |

## 边界规则

1. Controller 只处理协议、参数、日志和响应封装，业务编排进入 Service。
2. Backend 内跨领域调用使用明确 Service/DTO，不新增 Maven 中间模块或重复模型。
3. Agent 工具只调用 Backend 内部事实 API，不访问 MySQL、Backend Mongo 集合或券商适配器。
4. 任何真实交易仍由 Backend 的 Java 风控和券商执行链最终决定。
5. 迁移完成后只保留三模块路径和当前 API，不保留旧目录与兼容入口。
