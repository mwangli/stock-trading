# 系统架构需求

## 目标

构建个人使用的轻量级 A 股 T+1 自动真实交易系统。系统根据 LSTM 价格信号和新闻情感自动选股，经确定性风控后自动提交真实委托，全程不要求人工逐单确认。

## 必须能力

- 同步股票、日线、分钟线、交易日历、新闻和公告。
- 收盘后离线更新 LSTM 模型，生产交易时只做推理。
- 使用 LSTM 与情感模型生成候选排名。
- 提供历史回测，验证收益、回撤、费用和成交约束。
- 连接中信证券真实账户，读取资金、持仓、委托和成交。
- 自动执行买入、止损、止盈和 T+1 退出。
- 提供资金、仓位、单日亏损、可成交性和重复下单风控。
- 保留模型决策、风控结果、委托请求、券商回执和异常记录。

## 明确不建设

- 模拟账户、模拟资金和模拟订单。
- 人工逐单确认和手工下单页面。
- 模型审批、复杂生命周期平台和训练管理大屏。
- 通用参数优化器和通用动态任务管理页面。
- 在线训练或生产交易时临时训练。
- WebSocket、微信等具体通知渠道；当前只预留通知接口。
- 模型直接访问券商。

## 安全要求

- `TRADING_REAL_WRITE_ENABLED` 默认必须为 `false`。
- 数据、模型、券商会话或风控状态异常时禁止新开仓。
- 所有券商写操作必须经过 Java 风控和幂等检查。
- 前端不得以固定示例数据替代真实接口结果。
