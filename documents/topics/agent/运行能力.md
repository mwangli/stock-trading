# 运行能力

## 模块定位

Agent 运行能力负责 Provider 客户端、`AiServices` Agent、预算、熔断、并发、短期 Chat Memory、结构化输出解析及综合运行状态。它不承载具体业务事实，也不直接调用 Backend。

## 业务职责

- 注册和选择云端 Provider 或本地 Ollama 客户端。
- 使用 LangChain4j `AiServices` 创建类型化 `StrategyAgent`。
- 按任务绑定明确工具集合、会话记忆和结构化输出类型。
- 管理模型调用超时、最大输出、并发和每日预算。
- 维护 Provider 健康检查、熔断、冷却和模式切换。
- 汇总 Agent Core、Provider、Embedding 和 Backend Facts 状态。
- 解析结构化输出并将结果交给具体业务包处理。

## 职责分布

```text
client / config       # Provider、模型客户端和 LangChain4j 装配
client / model        # 类型化 Agent、Provider 客户端和运行模型
service               # Runtime、预算、熔断、并发和 Chat Memory
output                # 通用结构化输出接口与解析
controller / dto      # Runtime 管理、健康接口和 HTTP 契约
```

## 调用流程

```text
业务任务
  → AgentRuntimeCoordinator
  → 并发与预算检查
  → Provider 模式和健康状态检查
  → AiServices + 任务工具 + Chat Memory
  → 模型调用
  → 结构化输出解析
  → 业务结果或明确失败状态
```

## 状态模型

- `agentCoreStatus`：Agent 应用与核心编排是否可用。
- `providerStatus`：模型 Provider 是否可调用。
- `embeddingStatus`：本地 Embedding 是否可用。
- `backendFactsStatus`：Backend 权威事实是否可查询。

Backend 事实不可用不应触发 Provider 熔断，也不应使 Agent Core 整体为 DOWN。各状态由各自能力提供真实证据，Runtime 只负责汇总。

## 依赖边界

- 可以依赖 `tool` 提供的 `@Tool` 集合和执行上下文。
- 可以依赖知识相关 Service，但不直接操作其 Repository。
- 通过 `AgentFactQueryService` 获取事实源状态，并由该服务调用 Platform 权威事实。
- 不定义交易建议、交易计划或会话领域规则。

## 失败治理与扩展约束

Provider 超时、熔断、预算耗尽、并发受限、空响应和结构化解析失败必须分别记录。禁止把空文本、默认回答或无法验证的自由文本当作成功结果。日志记录任务、Provider、耗时、状态和错误码，不记录完整 Prompt、Token、Cookie 或未脱敏业务对象。

新增 Provider 时应复用统一 Runtime API，并明确超时、并发、预算、健康检查和删除条件。只有高层 `AiServices` 无法覆盖的场景才允许引入低层模型 API，并说明原因。

## 重点能力详细设计

### Runtime 输入门禁

`AgentRuntimeCoordinator` 只接受 `RESEARCH`、`DIAGNOSTIC`、`REPORT`、`TRADE_PLAN` 和 `TRADE_DECISION`。系统 Prompt 与用户 Prompt 必须非空；用户 Prompt 最大 20000 字符，系统 Prompt 最大 12000 字符。非法请求返回稳定错误码，不进入 Provider。

Agent 总开关关闭时返回 `DEGRADED/AGENT_DISABLED` 并保留已有事实摘要，不伪造模型结论。

### Provider 选择与回退

Provider 模式由 `AgentProviderModeManager` 管理：

| 模式 | 行为 |
|---|---|
| `deepseek` | 仅调用已完整配置的 DeepSeek |
| `ollama` | 仅调用已完整配置的 Ollama |
| `auto` | 优先 DeepSeek，失败后尝试 Ollama；未配置 DeepSeek 时直接使用 Ollama |
| `disabled` | 拒绝模型调用 |

每次调用按 Session 加锁，在线程池中执行，线程数为 `agent.maxConcurrency`。调用超时由 `agent.timeoutMs` 控制。工具只从 `AgentToolCatalog.resolve(allowedTools)` 绑定，模型不能使用未授权工具。

`FactSourceUnavailableException` 会立即返回 `FACT_SOURCE_UNAVAILABLE`，不会继续切换 Provider，也不会记录为模型失败。其他 Provider 异常才会进入回退和熔断逻辑。

### Chat Memory 两阶段提交

Runtime 不让失败调用直接修改正式会话记忆：

```text
正式 ChatMemory
  → snapshot 创建独立尝试副本
  → Provider 在副本中写入本轮消息
  → stage 暂存成功模型调用
  → 结构化输出校验成功后 commit
  → 超时、工具失败、解析失败时 discard
```

正式 Memory 使用 `MessageWindowChatMemory`，最大消息数由 `agent.chatMemoryMaxMessages` 控制且不低于 2。该设计保证无效 JSON、超时重试和备用 Provider 尝试不会污染后续上下文。

### 结构化输出处理

Provider 完成后，`AgentStructuredOutputParser` 按 `outputType` 选择 Handler，并把允许的 Evidence 引用传入校验。解析成功才返回 `COMPLETED` 并提交 Chat Memory。

本地 Ollama 的 `RESEARCH` 输出若不是合法 JSON，会返回受控 `DEGRADED/OLLAMA_STRUCTURED_OUTPUT_DEGRADED`，隐藏原始文本，不把自由文本当成研究结论。其他类型解析失败返回 `STRUCTURED_OUTPUT_INVALID`。

### Provider 熔断

熔断按 Provider 独立维护连续失败次数：

- 达到 `circuitBreakerFailureThreshold` 后进入 `OPEN`。
- 持续 `circuitBreakerOpenDurationMs` 后进入 `HALF_OPEN`。
- 半开期间只允许一个探测调用。
- 成功后清零并回到 `CLOSED`。
- 关闭熔断配置时状态为 `DISABLED`。

熔断只保护模型调用，不保护 Backend 事实查询，也不参与任何真实交易门禁。

### DeepSeek 每日预算

`AgentApiBudgetManager` 以北京时间按天在 MongoDB 维护 `agent_api_daily_budgets`：

1. 调用前使用 Prompt 和 Chat Memory 的 UTF-8 字节数保守估算输入 Token。
2. 加入协议预留 Token、最大输出 Token、峰值单价和安全系数。
3. 使用 MongoDB `findAndModify` 原子增加 `allocatedCostMicros`。
4. 预算不足返回 `AGENT_DAILY_BUDGET_EXCEEDED`。
5. 成功后按 Provider `TokenUsage` 结算并释放差额。
6. Token 统计缺失、调用失败或超时时保留全部预留，执行保守结算。
7. 预算存储不可用时返回 `AGENT_DAILY_BUDGET_UNAVAILABLE` 并阻止调用。

预算只限制 DeepSeek，不限制 Ollama。金额以人民币微元整数保存，避免浮点累计误差。

### 运行状态与管理 API

| API | 设计 |
|---|---|
| `GET /api/agent/runtime/status` | 返回配置、Provider、Embedding、事实源等综合状态 |
| `GET /api/agent/runtime/health` | 执行脱敏健康检查；该接口免登录 |
| `PUT /api/agent/runtime/provider` | 切换运行时 Provider 模式 |
| `GET /api/agent/runtime/apiBudget` | 查询当天 DeepSeek 预算快照 |

健康检查使用不消耗业务 Token 的 Provider 模型列表检查。状态接口必须区分“已配置”和“实际可达”，不能把 Bean 存在当作 Provider 健康。

## 扩展设计要求

新增输出类型需要同时扩展支持集合、Handler 和业务 DTO。新增 Provider 需要实现配置完整性、健康检查、超时、错误码、熔断、预算策略和状态展示。任何重试设计都必须继续使用 Memory 快照，不能复用已被失败尝试修改的对象。
