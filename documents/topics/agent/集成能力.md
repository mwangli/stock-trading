# 集成边界

Agent 与 Backend 运行在同一个 Spring Boot 进程。固定依赖方向为：

```text
base → data → model → trading → platform → agent → application
```

Agent 直接依赖 Platform 公开 Service，并将 Platform DTO 转换为自身只读事实模型。Platform 可以调用 Model 和 Trading 的公开 Service，但不复制排名、盘口定价、订单轮询或资金竞争逻辑。

## 当前事实流

```text
Agent Tool
→ AgentFactQueryService
→ InternalAgentFactsService
→ PredictionCandidateQueryService / Trading 查询 Service / Job 查询 Service
→ Platform DTO
→ Agent Fact
```

## 约束

- Agent 不访问 Model、Trading 或 Platform Repository 和 Entity。
- Agent 不查询已删除的策略状态、自适应策略或交易门禁。
- 模型排名以预测批次为权威，Agent 不持久化另一套候选排名。
- 订单、成交和持仓以券商同步事实为权威。
- 事实查询失败时明确返回不可用，不使用模型猜测替代。
- 不为同 JVM 单实现调用重新增加内部 HTTP、Port、Adapter 或兼容模块。
