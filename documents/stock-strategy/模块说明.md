# stock-strategy 领域说明

## 领域定位

`com.stock.strategy` 是 `stock-backend` 内部的确定性策略领域，将市场数据、模型预测、情感结果和配置规则转换为排名、信号、卖出判断和回测结果，不是独立 Maven 模块。

## 核心能力

| 能力 | 说明 |
|---|---|
| 候选筛选 | 按价格、成交量、预测、新闻影响和业务门槛过滤股票 |
| 综合评分 | 聚合模型、趋势、技术指标和风险因素 |
| 信号生成 | 生成结构化买入、持有、卖出或跳过信号 |
| 策略状态 | 管理配置、运行模式和当前生效状态 |
| 卖出判断 | 处理止盈、止损、移动止损和盘中退出条件 |
| 回测 | 使用历史股票池和行情复现策略表现 |

## 实现与存储

策略配置和运行状态属于常规业务状态，保存在 MySQL。排名、信号、决策结果、回测运行和回测成交属于增量结果，保存在 MongoDB。

策略引擎由计算器、选择器、决策聚合器和状态管理器组成。回测数据装载、资金场景、成交计算、执行编排、数据审计和结果持久化保持职责分离。

## 决策边界

- 策略结果是 Java 基线，不等同于最终订单。
- 候选必须携带来源批次、策略版本和有效期。
- 数据不完整、候选过期或交易事实不确定时应跳过。
- Agent 可基于候选生成独立建议，但建议不改变策略候选或自动交易结果。
- 真实交易前仍由 `com.stock.trading` 重新读取当前事实并执行硬风险校验。
