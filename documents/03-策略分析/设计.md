# 策略分析设计

## 选股流程

```text
已训练 LSTM 股票池
  -> LSTM 真实推理
  -> 查询近期新闻与公告
  -> 情感模型真实推理
  -> 分数加权与排序
  -> 可成交性和风控过滤
  -> 交易候选
```

## 状态管理

单实例部署下，短期运行状态保存在后端内存；需要审计和恢复的数据写入 MySQL 或 MongoDB。不增加独立缓存或消息组件。

## 调度

所有周期任务通过 `JobConfig + JobSchedulerService` 注册和执行，不在业务类中使用 `@Scheduled`。

## 回测

历史回测与真实交易事实隔离。回测必须避免前视数据，使用下一根可成交价格，并计入最低佣金、税费和滑点。

## 失败处理

- 行情不完整：排除该股票。
- 所有 LSTM 推理失败：本次选股失败。
- 情感模型失败：本次选股失败。
- 券商状态不可用：禁止真实委托。
