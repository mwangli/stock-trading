# 策略领域

## 领域定位

`com.stock.strategy` 是 Backend 的确定性策略领域，将市场事实、模型预测、情感结果和配置规则转换为排名、信号、卖出判断和回测结果。

## 选股与信号

```text
合格股票池
  → 数据完整性和可交易性过滤
  → 模型、情感与技术指标计算
  → 业务门槛过滤
  → 综合评分
  → 排名、信号和候选批次
```

候选优先排除数据不足、价格或成交量不合格、不可交易及预测过期的股票。输出携带信号、得分、理由、来源批次、策略版本和有效期，不能仅靠高分掩盖基础数据问题。

## 策略状态与卖出判断

策略配置描述参数，运行状态描述当前模式和生效版本，切换日志记录原因。自动切换需要数据门槛、冷却时间和回退能力。

卖出判断可以考虑止盈、止损、移动止损、时间退出和技术指标变化。真实持仓、T+1 可卖数量和最终价格由交易领域重新确认。

## 回测

回测用于比较规则和参数，不承诺真实收益。它使用当时有效的历史股票池和决策时点前已产生的数据，处理停牌、涨跌停、上市和退市状态，并计入佣金、最低佣金、印花税和滑点假设。

结果至少区分累计收益、最大回撤、胜率、交易次数、费用和数据覆盖。参数、策略版本、费用版本和跳过原因随结果保存。

## 存储与边界

策略配置和运行状态保存到 MySQL；排名、信号、决策结果、回测运行及回测成交保存到 MongoDB。

策略结果是交易前置输入，不是最终订单。Agent 可以独立评估候选，但不能修改策略候选或自动交易结果。真实委托前的最新事实和硬风险校验由交易领域负责。
