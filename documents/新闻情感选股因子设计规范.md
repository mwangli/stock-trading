# 新闻情感选股因子设计规范

## 1. 目标

将新闻文本分析从“正面 / 中性 / 负面”分类升级为可供选股策略消费的新闻影响因子，解决大量中性结果无法指导选股的问题。

本阶段采用最简单一路径：保留现有三分类模型，复用现有事件类型和优先级，在聚合层生成 `newsImpactScore`。暂不新增模型服务、兼容接口、重复 DTO 或独立事件分类链。

## 2. 业务定义

情感标签只表示文本语气，不代表股价方向。策略使用的新闻影响因子定义为：

```text
newsImpactScore = polarityScore
                 × impactMagnitude
                 × calibratedConfidence
                 × timeDecay
```

其中：

- `polarityScore`：模型输出的正负方向，范围 `[-1, 1]`；
- `impactMagnitude`：由事件类型、信息优先级和新闻覆盖度得到，范围 `[0, 1]`；
- `calibratedConfidence`：模型置信度和新闻覆盖度的合成值；
- `timeDecay`：按照事件类型半衰期衰减。

中性新闻的方向分数为零，因此不会被强行转换为固定的 `0.5` 交易因子。无新闻或不可交易新闻不参与情感权重，保持 LSTM 因子原值。

## 3. 输出契约

`SentimentAggregateResult` 只输出当前策略需要的字段：

| 字段 | 说明 |
|---|---|
| `newsImpactScore` | 方向性新闻影响，范围 `[-1, 1]` |
| `impactMagnitude` | 事件影响强度，范围 `[0, 1]` |
| `actionable` | 是否达到进入选股排序的最低门槛 |
| `dominantEventType` | 聚合窗口内权重最高的事件类型 |
| `effectiveHorizonHours` | 当前事件影响窗口 |

强负面事件仍通过 `strongNegative` 独立触发买入阻断，不与普通新闻影响分数混为一谈。

## 4. 评分规则

1. 事件先按内容摘要去重，再按模型置信度、发布时间、来源、事件类型和重复数量加权。
2. `impactMagnitude` 使用已有 `informationPriority`，不新增第二套事件优先级。
3. 只有 `actionable=true` 的新闻影响才进入综合评分。
4. 没有可交易新闻影响时，综合分数直接使用 LSTM 分数，不引入固定中性基线。
5. 强负面事件先执行风险阻断，再执行普通排序。

## 5. 分阶段实施计划

### 阶段一：业务样本和评估基线

- 扩充业绩、订单、回购、增持、减持、监管、诉讼、重组、股东行为、行业传导、标题正文冲突、重复报道和伪信号样本；
- 每条样本增加事件类型、影响方向、影响强度、有效窗口和策略动作标签；
- 计算情绪分类指标、方向准确率、影响强度 MAE、样本中性占比、事件类型覆盖率和可交易新闻占比；
- 评估页面展示模型版本、评估集版本、样本数、中性占比、正负面召回率、事件类型覆盖率、可交易新闻占比和评估时间。

### 阶段二：事件和影响模型

- 使用现有事件类型作为唯一事件分类契约，先提供可解释规则基线；
- 逐步用人工标注数据训练事件识别和影响强度模型；
- 增加模型拒答、影响方向和有效窗口输出，避免把文本情绪直接当成价格方向。

### 阶段三：历史行情回放

- 将新闻发布时间与未来 `T+1`、`T+3`、`T+5` 的行业或市场超额收益关联；
- 计算超额收益 IC、Top-K 新闻命中率、Top-K 股票组合收益、最大回撤和换手率；
- 对比 LSTM 单因子、LSTM + 当前新闻因子、LSTM + 新影响因子的样本外增量收益。

### 阶段四：交易成本和策略门禁

- 统一扣除佣金、过户费、印花税、滑点和最小安全边际；
- 只有成本后收益、回撤和稳定性满足门槛时，才允许提高新闻因子权重；
- 真实交易仍由 Java 权限、风控、交易日、幂等和执行隔离决定，模型评估不能自动开启交易。

## 6. 评估指标定义

| 指标 | 当前阶段 | 定义 |
|---|---|---|
| 事件识别 F1 | 阶段二 | 预测事件类型与人工事件类型的 Macro-F1 |
| 影响方向准确率 | 阶段一 | 预测新闻影响方向与人工方向标签一致的比例 |
| 影响强度 MAE | 阶段一 | `abs(predictedMagnitude - expectedMagnitude)` 的平均值 |
| T+1/T+3/T+5 超额收益 IC | 阶段三 | 新闻影响分数与未来超额收益的横截面相关性 |
| Top-K 新闻命中率 | 阶段三 | 最高影响新闻中达到预设超额收益阈值的比例 |
| Top-K 股票组合收益 | 阶段三 | 使用新闻因子选出的股票组合收益 |
| 最大回撤 | 阶段三 | 回测净值相对历史峰值的最大跌幅 |
| 换手率 | 阶段三 | 组合调仓交易金额与组合规模的比例 |
| 成本后收益 | 阶段四 | 扣除实际配置交易成本后的收益 |
| LSTM 增量收益 | 阶段三 | 新闻增强策略相对 LSTM 基线的样本外收益差 |

阶段一的影响强度指标是“文本影响基线”，不能替代阶段三的价格影响验证；行情数据不足时必须显示“未评估”。

## 7. 后续数据和模型演进

后续训练数据应将新闻发布时间与未来 `T+1`、`T+3`、`T+5` 的行业或市场超额收益关联，补充事件方向、影响强度和持续时间标签。训练、验证和测试必须按时间切分，禁止未来信息泄漏。

模型验收除分类指标外，还必须包含事件方向、影响强度、超额收益 IC、Top-K 命中率、换手率、最大回撤和扣除交易成本后的增量收益。只有新闻因子相对 LSTM 基线产生稳定的样本外增量收益，才允许提高策略权重。

## 8. 当前实现范围

本次实现只改动新闻聚合、选股评分、候选快照和候选展示字段：

- 用 `newsImpactScore` 替代语义不准确的 `sentimentScore`；
- 中性或无新闻不再获得固定 `0.5` 情感因子；
- 选股排名保存事件影响分数；
- 评估集增加业务标签，并展示阶段一可计算的评估指标；
- 对尚未接入历史行情的收益类指标明确显示未评估；
- 不增加兼容字段、旧 URL、旧 DTO 或重复适配层。
