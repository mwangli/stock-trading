```mermaid
flowchart LR
    Data[stock-data 市场事实] --> Model[stock-model 模型]
    Model --> Strategy[stock-strategy 策略]
    Strategy --> Trading[stock-trading 交易]
    Platform[stock-platform 调度] --> Data
    Platform --> Model
    Platform --> Strategy
    Agent[stock-agent 增强] -. 只读事实 .-> Platform
    Agent -. 受控建议 .-> Strategy
    Frontend[Frontend] --> Agent
    Frontend --> Trading
```
