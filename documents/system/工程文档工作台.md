flowchart LR
    Data[stock-data 市场事实] --> Model[stock-model 预测与排名]
    Model --> Trading[stock-trading 分阶段交易]
    Platform[stock-platform 调度] --> Data
    Platform --> Model
    Platform --> Trading
    Agent[stock-agent 只读增强] -. 模型排名、任务、订单、成交 .-> Platform
    Frontend[stock-client] --> Agent
    Frontend --> Trading
