# 策略分析需求

## 输入

- LSTM 下一交易日预测收益率。
- 最近 36 小时新闻与公告情感分数。
- 最新行情、成交量和可成交状态。
- 当前账户资金、持仓和风险状态。

## 输出

- 候选股票代码和名称。
- LSTM 得分、情感得分、综合得分和排名。
- 推荐买入区间、最大数量和失效条件。
- 结果生成时间和数据截止时间。

## T+1 规则

- T 日收盘后生成候选。
- T+1 日开盘后确认分钟级价格和成交量再买入。
- 当日买入不得当日卖出。
- 下一交易日按止损、止盈、移动止盈、信号反转或收盘前规则退出。

## 风控

- 单股仓位上限。
- 总仓位上限。
- 单日最大亏损。
- 连续失败熔断。
- 停牌、涨跌停、流动性和可卖数量校验。
- 最低佣金、印花税和滑点进入回测与资金分配。
