# 情感分析数据源补充需求

## 1. 背景

当前情感分析主要消费股票新闻和公告。为了提高事件覆盖率，需要在保留现有证券平台数据源的基础上，补充东方财富 F10 相关信息，重点覆盖公司公告、业绩披露、监管风险、股东和高管变动、重大经营事项及资金风险事件。

新增数据必须服务于两个目标：

1. 为情感模型提供标题、正文和发布时间完整的文本样本。
2. 为交易候选生成提供可解释的事件类型、风险等级和信息时点约束。

东方财富网页后台接口不是稳定公开 API。需求只规定业务信息和数据质量，不把具体请求地址、字段顺序或页面脚本实现视为永久契约；接入前必须以实际响应和来源版本完成适配确认。

## 2. 范围

### 2.1 纳入范围

| 优先级 | 数据主题 | 业务用途 |
| --- | --- | --- |
| P0 | 公司公告标题和正文 | 情感分析、重大事件识别、信息时点控制 |
| P0 | 业绩预告、业绩快报、定期报告 | 判断盈利预期变化和经营质量 |
| P0 | 监管问询、处罚、立案、违规、诉讼仲裁 | 负面风险门禁和强负面识别 |
| P1 | 股东增持/减持、高管持股和任职变动 | 判断供给压力、治理信号和管理层变化 |
| P1 | 重大合同、订单、中标、投资、并购和合作 | 识别经营改善或重大不确定性 |
| P1 | 限售解禁、融资融券、龙虎榜、大宗交易、股权质押 | 形成资金拥挤度和交易风险特征 |
| P2 | 公司简介、主营业务、行业、管理层履历 | 低频补充公司画像，不直接作为短期情绪 |

### 2.2 不在范围内

- 不以东方财富数据替代现有证券平台新闻和公告数据源。
- 不把未经核验的网页展示字段直接作为模型特征或交易门禁。
- 不采集与股票无法建立可靠关联的泛市场资讯作为个股情感样本。
- 不在本需求中决定模型结构、训练参数或生产模型版本切换策略。

## 3. 业务规则

### BR-SENTIMENT-SOURCE-01 来源分层

公司公告、业绩披露和监管风险属于高优先级事件；股东/高管变动、重大经营事项和资金风险属于中高优先级事件；公司画像属于低频基础资料。来源优先级必须写入事件记录，供采集重试和情感聚合使用。

### BR-SENTIMENT-SOURCE-02 信息时点

情感分析只允许使用 `publishedAt <= informationCutoffAt` 的事件。晚于预测或选股截止时间的数据不得进入该批次结果，避免未来信息泄漏。

### BR-SENTIMENT-SOURCE-03 事件分类

每条事件至少归入以下一种类型：`EARNINGS`、`REGULATORY_OR_LITIGATION`、`SHAREHOLDER_OR_EXECUTIVE`、`MATERIAL_BUSINESS`、`CAPITAL_RISK`、`GENERAL_ANNOUNCEMENT`、`GENERAL_NEWS`。

### BR-SENTIMENT-SOURCE-04 去重

同一股票、同一来源、同一来源事件编号只能形成一条主记录。没有稳定事件编号时，使用股票代码、规范化标题、发布时间和正文摘要计算内容指纹；跨来源重复事件应进入同一事件组，不重复放大情感权重。

### BR-SENTIMENT-SOURCE-05 原文优先

标题、正文、来源、发布时间和来源事件编号必须保留原始值；清洗文本只能作为模型输入副本，不能覆盖原文。

### BR-SENTIMENT-SOURCE-06 失败可追溯

来源超时、限流、空响应、字段变化和正文缺失必须分别记录，不得把空数据当成“没有负面信息”，也不得推进该来源的成功水位。

### BR-SENTIMENT-SOURCE-07 风险优先

监管处罚、立案、重大诉讼、退市风险、财务造假和债务违约等事件，必须能够独立触发强负面检查，不得因普通新闻稀释其影响。

## 4. 验收标准

- 给定股票和截止时间，系统能够区分公告、业绩、监管、股东/高管、经营事项和资金风险事件。
- 同一来源事件重复拉取不会新增重复记录；跨来源相同事件不会被重复计权。
- 任何晚于 `informationCutoffAt` 的事件都不会出现在情感聚合输入中。
- 监管和重大风险事件能够在情感聚合结果中保留事件标题和强负面原因。
- 来源空响应、超时、限流和正文缺失均能被区分并进入可重试状态。
- 现有证券平台新闻/公告采集在新增来源失败时仍可独立完成，新增来源不能阻断原有采集链路。
- 采集结果能够按来源、事件类型、发布时间和股票代码查询，支持后续模型训练样本筛选。

## 5. 依赖与约束

- 采集必须接入统一的 `JobConfig + JobSchedulerService` 调度体系。
- 事件数据需要与股票代码、预测批次和情感模型版本建立可追溯关系。
- 东方财富接口的字段含义、分页方式、详情请求和限流策略必须在接入评审中以真实样本确认。
- 生产环境不得把来源密钥、Cookie 或临时认证信息写入代码、文档和提交记录。
