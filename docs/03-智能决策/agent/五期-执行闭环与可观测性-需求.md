# AGENT 五期执行闭环与可观测性需求

## 1. 阶段定位

第五阶段承接第四阶段的双 Provider、结构化输出、只读证据和 `TradePlanDraft` 落库能力，将交易计划从“待复核草案”推进到可追踪的 Java 执行闭环。

本阶段不改变真实交易默认关闭的安全边界，不允许 Agent 直接调用券商写接口。所有交易写入必须经过 `tradingExecutor` 的当前事实复核、风控、幂等抢占和 `TRADING_REAL_WRITE_ENABLED` 门禁。

## 2. 建设目标

1. 建立唯一、合法、可审计的 TradePlan 状态机。
2. 在任何券商写操作前重新读取交易日、行情、账户、持仓、当日委托和风控事实。
3. 使用数据库条件更新和版本控制防止重复执行。
4. 将 Provider 配置状态、连通性、模型可用性和调用失败原因区分展示。
5. 将当前策略配置页中的 Agent 对话拆分为独立 Agent 工作台。
6. 为执行状态、Provider 调用和工具调用补充可观测字段与脱敏审计。

## 3. TradePlan 状态机

允许的状态转换：

```text
PENDING_REVALIDATION -> EXPIRED
PENDING_REVALIDATION -> RISK_REJECTED
PENDING_REVALIDATION -> EXECUTING
EXECUTING             -> EXECUTED
EXECUTING             -> FAILED
```

约束：

- Agent 只能生成 `PENDING_REVALIDATION`。
- `EXECUTING` 只能由执行服务通过条件更新获得。
- `EXECUTED`、`FAILED`、`RISK_REJECTED`、`EXPIRED` 为终态。
- 所有状态变化必须保存原因、traceId、更新时间和执行批次信息。
- 真实写入关闭时，不得调用券商写接口。

## 4. 当前事实复核

执行服务必须在调用 `TradeExecutor` 前确认：

- 当前日期是已确认的交易日；
- 计划未过期，且目标交易日与当前执行窗口一致；
- 当前行情、账户资金和持仓可读取；
- 买入金额或卖出数量满足最小交易单位；
- 卖出数量不超过可卖持仓，满足 T+1；
- 当日不存在同一幂等键或同股票同方向重复委托；
- 当前候选批次、预测批次和策略版本仍然一致；
- `RiskController` 通过；
- `TRADING_REAL_WRITE_ENABLED=true`。

## 5. Provider 运行状态

Provider 状态至少区分：

```text
DISABLED
CONFIGURED
REACHABLE
MODEL_NOT_FOUND
READY
TIMEOUT
UNAVAILABLE
```

错误响应必须区分 DeepSeek、Ollama、超时、模型不存在、连接失败和双 Provider 全部失败，不能返回 API Key、Authorization Header 或完整 Prompt。

## 6. RAG 与 Memory 的阶段边界

RAG 和长期 Memory 不属于第五阶段交易执行安全链：

- 第五阶段只保留当前已有的短期会话 Memory、RAG 配置状态和安全降级标识；
- 不允许 RAG 或长期 Memory 覆盖实时行情、账户、持仓、交易日和风控事实；
- RAG 与长期 Memory 的正式落地安排在第六阶段“知识检索与记忆增强”；
- 第六阶段必须先完成用户范围权限、证据状态、Embedding 版本、数据过期和删除纠错机制；
- `hash-32` 只能作为明确标记的降级方案，不能对外宣称为语义检索。

## 7. 验收标准

| 编号 | 验收标准 |
|---|---|
| AGENT5-AC-001 | 非法 TradePlan 状态转换被拒绝。 |
| AGENT5-AC-002 | 同一计划并发执行最多只有一个执行者。 |
| AGENT5-AC-003 | 真实写入关闭时不调用券商写接口。 |
| AGENT5-AC-004 | 计划执行失败、风险拒绝和过期均有明确原因。 |
| AGENT5-AC-005 | Provider 状态不再把“配置完成”直接等同于“可用”。 |
| AGENT5-AC-006 | Agent 页面可展示计划、证据、状态和执行结果。 |
| AGENT5-AC-007 | RAG/Memory 不参与实时交易事实覆盖。 |
| AGENT5-AC-008 | 关键状态转换、Provider 调用和工具调用不记录敏感信息。 |

## 8. 验证边界

本阶段默认只执行文档、源码、契约、差异和静态安全检查。未获得当前请求的额外授权时，不执行 Maven 编译、前端构建、测试、应用启动、真实模型调用、数据库迁移或线上交易验证。

源码检查通过不等于编译通过；模拟 Provider 测试通过不等于 DeepSeek/Ollama 真实可用；TradePlan 进入 `EXECUTED` 不等于券商最终成交，除非有真实订单和成交证据。
