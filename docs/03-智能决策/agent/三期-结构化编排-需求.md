# AGENT 三期结构化编排需求

## 1. 阶段定位

三期承接二期 LangChain4j Runtime、Tool Gateway、RAG 和 Memory 基础设施，完成 Research、Diagnostic、Report 的结构化编排闭环。

本阶段的目标是让模型只负责组织已经取得的证据，业务服务负责工具白名单、证据边界、结果校验和任务状态。三期不扩大真实交易写入范围。

## 2. 建设目标

1. 为 Research、Diagnostic、Report 建立明确且互不混用的结果 DTO。
2. 统一通过显式注册的只读工具获取结构化业务证据。
3. 将工具结果、RAG 结果和 Memory 摘要统一收敛为受限证据集合，再交给模型组织结论。
4. 结构化输出失败、证据不足、工具异常和模型不可用时，任务必须进入可解释的失败或降级状态。
5. 任务落库保存结果类型、结构化结果摘要、不确定性和证据引用，避免只保存一段自由文本。
6. 为后续 TradePlan 生成保留稳定的证据契约，但本阶段不生成券商订单，也不改变交易执行权责。

## 3. 功能需求

### 3.1 结果契约

- Research 结果至少包含摘要、结论状态、结论要点、证据引用、不确定性和后续建议。
- Diagnostic 结果至少包含总体状态、检查项、阻断原因、证据引用和不确定性。
- Report 结果至少包含报告日期、固定章节、证据引用、数据质量和不确定性。
- 三类结果必须使用明确 DTO，不允许以 `Map` 或任意自由文本作为对外业务结果。
- `TradePlanDraft` 不属于本阶段的模型输出结果，仍由后续阶段单独实现。

### 3.2 显式工具编排

- Runtime 只能接收当前任务允许的工具定义，不接收模型传入的工具名、SQL、Mongo 查询、URL、Bean 名称或方法名。
- Research、Diagnostic、Report 使用各自固定的只读工具集合。
- 工具返回值必须包含来源、状态、时间、错误码和脱敏后的数据摘要。
- 工具失败时，模型不得把缺失数据补成正常值；只能返回 `UNKNOWN`、`DEGRADED` 或 `FAILED`。

### 3.3 证据边界

- 结构化业务工具事实优先于 RAG 和 Memory。
- 每条证据必须包含 `evidenceId`、来源类型、来源标识、事实时间和可信状态。
- RAG 或 Memory 不可用时，Research 可以降级；Diagnostic 和 Report 不得伪造完整结论。
- 证据集合只允许由应用服务构造，模型不能修改证据来源和事实值。

### 3.4 任务持久化

- `agent_task` 保存 `result_type`、`structured_result`、`uncertainty` 和 `evidence_refs`。
- `COMPLETED` 只表示结构化结果通过解析和基础校验，不表示交易成功或收益成立。
- 模型不可用但存在可靠结构化事实摘要时使用 `DEGRADED`。
- 结构化输出解析失败、必要字段缺失或工具结果不可用时使用 `FAILED`。

## 4. 非功能约束

- 不新增 `@Scheduled`，日报继续通过统一任务调度中心。
- 不新增人工审批状态或 `/approve`、`/reject` 接口。
- 不调用券商写接口，不修改 `TRADING_REAL_WRITE_ENABLED`，不绕过交易风控。
- 不引入新的向量数据库、子 Agent、自动工具循环或第二套 Runtime 入口。
- 接口继续使用 `ResponseDTO<T>` 和明确 DTO。

## 5. 验收标准

| 编号 | 验收标准 |
|---|---|
| AGENT3-AC-001 | Research、Diagnostic、Report 使用不同的结构化结果 DTO。 |
| AGENT3-AC-002 | 三类任务的工具集合由代码显式注册，模型不能提交任意工具标识或查询语句。 |
| AGENT3-AC-003 | 工具证据包含来源、时间、状态和错误码，并进入统一证据集合。 |
| AGENT3-AC-004 | 结构化输出缺字段、解析失败或状态非法时，任务不会落库为 `COMPLETED`。 |
| AGENT3-AC-005 | 任务落库保存结果类型、结构化结果摘要、不确定性和证据引用。 |
| AGENT3-AC-006 | RAG、Memory 或模型不可用时，系统按规则降级，不以零值或猜测替代事实。 |
| AGENT3-AC-007 | 本阶段没有人工审批、券商写入和新增定时注解。 |

## 6. 验证边界

本阶段默认只执行源码、文档、UTF-8、标记边界、定向符号和差异检查。未获得当前请求明确授权时，不执行 Maven 编译、测试、应用启动、模型调用、数据库迁移、浏览器验证或线上验证。

源码检查通过不等于编译通过；结构化契约落库不等于模型运行和交易执行已验证。
