# 模型服务设计

## 职责

模型能力直接运行在 Java 单体后端内，不拆分独立 Python 服务。

## LSTM

- 候选池只包含训练记录标记为成功的股票。
- 使用最新历史价格构造输入并执行真实模型推理。
- 输出下一交易日预测价格和预测收益率。
- 推理失败的股票不进入候选池。

## 情感分析

- 输入为股票最近 36 小时的真实新闻和公告。
- 每只股票最多读取最近 20 条。
- 标题与正文合并后执行本地情感模型推理。
- 按置信度加权得到 `[-1, 1]` 的综合情感分数。
- 没有新闻按中性处理。
- 模型无法加载或推理失败时，整次选股失败。

## 综合评分

初始使用 LSTM 70%、情感 30%。实际权重必须通过滚动回测调整。XGBoost 和 LightGBM 仅在样本外结果证明能提高月收益稳定性后加入。

## 模型运行要求

- 模型目录通过配置指定并挂载到容器。
- 推理结果记录股票、模型标识、行情截止时间和计算时间。
- 不允许随机结果、固定分数或规则结果替代交易模型输出。
