# 模型服务设计

## 职责

模型能力直接运行在 Java 单体后端内，不拆分独立 Python 服务。模型只输出候选信号，不持有券商凭据，也不直接调用交易接口。

完整方案、证据和迁移边界见 [全市场共享股票预测模型详细设计](../2026-10-08-全市场共享股票预测模型详细设计.md)。

## LSTM 共享基础模型

- 全市场股票共用当前生效模型 `global-shared-base`，不再维护数千个完整逐股模型。
- 各股票分别构造 60 日滑动窗口后合并为 Panel Dataset，禁止跨股票拼接时间序列。
- 输入使用相对量价、技术指标、股票身份、行业、市场身份和历史成交额流动性特征。
- 当前市值和换手率没有逐日历史快照，禁止回填到历史样本；具备时点数据后再加入。
- 标签为缩放后的下一交易日收益率，不再直接训练绝对收盘价。
- 训练集和验证集按时间顺序切分并设置 purge gap。
- 在完整历史区间内均匀抽取窗口，并通过全市场样本上限控制内存，不随机打乱时间顺序。
- 模型、特征、标签、输入维度和收益率缩放版本必须一致，旧版本不得被新推理链加载。
- 全市场候选使用一次模型加载和批量前向传播。
- 当前仅实现共享基础模型；分组 Head 和轻量个股 Head 必须在样本外结果证明增益后增加。

## 情感分析

- 输入为股票最近 36 小时的真实新闻和公告，每只股票最多读取最近 20 条。
- 交易候选必须使用真实情感模型严格推理；模型无法加载或推理失败时停止生成候选。
- 同一事件按标题和正文指纹去重，只执行一次模型推理。
- 聚合权重包含模型置信度、时间衰减、来源权重、事件类型权重和转载惩罚。
- 无新闻按低置信度中性处理。
- 退市、财务造假、立案调查等强负面事件形成独立标志，由确定性选股链阻断买入。

## 综合评分

LSTM 收益率先映射为统一排序分数，再与事件情感分数组合。权重属于固定策略配置，必须通过 Walk-forward、Rank IC 和扣费后 Top-K 收益验证，不建设通用在线参数优化器。

## 训练与发布

- 共享 LSTM 只在收盘后离线训练，当前更新周期为最长 30 天。
- 生产交易期间禁止训练、下载、切换或临时替换模型。
- 当前只保存生效共享模型和必要版本元数据。
- 推理结果必须可追溯到模型文档 ID、模型版本和特征版本。

## 失败原则

- 共享模型缺失或版本不兼容：停止 LSTM 候选生成。
- 某股票行情不足或输出异常：跳过该股票。
- 情感模型失败：停止整次真实候选生成。
- 不允许使用随机结果、固定分数或规则结果替代交易模型输出。
