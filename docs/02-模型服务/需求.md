# 02-模型服务需求文档

## 文档信息

## 1. 模块目标

模型服务负责使用全市场共享 LSTM 和真实财经情感模型生成可比较、可追溯的候选信号。模型不得直接调用券商，所有真实交易必须继续经过 Java 策略、风控和执行链。

## 4. 数据要求

### 4.1 LSTM 输入

- 至少 60 个交易日的 OHLCV 数据。
- RSI、MACD、均线偏离、布林带位置和 OBV 相对量。
- 股票身份、行业代码、市场身份和历史成交额流动性。
- 所有特征只能使用计算时点及之前数据。

### 4.2 模型输出

- 下一交易日预测收益率。
- 根据最新收盘价还原的预测价格。
- 模型文档 ID 和版本信息。

### 4.3 情感输入输出

- 输入为最近 36 小时真实新闻和公告。
- 输出为 `[-1, 1]` 情感分数、覆盖置信度、独立事件数量和强负面标志。

## 5. 训练和发布约束

- 不提供在线训练页面、人工模型切换、模型审批或通用参数优化器。
- 训练任务通过统一调度中心收盘后执行。
- 只保留当前生效共享模型和必要元数据。
- 旧逐股模型不得被新共享推理链加载。

## 6. 验收要求

- 代码层不存在跨股票窗口拼接。
- 训练和推理使用同一特征计算逻辑。
- 共享模型只加载一次即可完成批量预测。
- 模型和情感任一关键链路失败时不产生替代交易分数。
- 实际效果必须通过 Walk-forward、Rank IC、Top-K 扣费后收益、最大回撤和换手率验证。
- 静态检查或训练损失下降不能单独证明真实交易盈利。
