# 系统架构设计

## 组件

```text
React PC
          |
Java Spring Boot 单体后端
  | 数据采集 | 模型推理 | 策略与风控 | 调度 | 中信交易 |
          |
 MySQL + MongoDB
```

## 分工

- 前端只展示和操作，不承载交易规则。
- Java 后端统一处理采集、LSTM、情感分析、策略、风控、调度和交易。
- MySQL 保存配置、任务和真实交易事实。
- MongoDB 保存历史行情、新闻和模型参数。
- Backend 进程内缓存短时有效的券商 Token；应用重启后自动重新登录，不持久化真实登录凭据。
- 后端内部直接调用服务，不增加消息中间件。

## Docker

基础服务为 `stock-web`、`stock-backend`、`stock-mysql` 和 `stock-mongo`。只维护开发和生产两套覆盖配置。

## 故障原则

- 数据失败：停止计算。
- 模型失败：停止生成候选。
- 风控失败：禁止委托。
- 券商失败：保留本地记录并等待重新对账。
- 页面失败：显示错误或空状态，不伪造数据。
