# 系统架构需求

## 目标

构建一个面向个人使用的轻量级 A 股 T+1 真实交易系统，核心目标是长期稳定的月收益率，而不是平台化能力。

## 必须能力

- 同步股票、日线、分钟线、交易日历、新闻和公告。
- 加载 LSTM 与情感分析模型并生成候选排名。
- 提供历史回测，验证收益、回撤、费用和成交约束。
- 连接中信证券真实账户，读取资金、持仓、委托和成交。
- 支持人工确认交易和无人值守交易。
- 提供仓位、止损、单日亏损、重复下单等基础风控。
- PC 展示核心数据；微信小程序后续用于通知和人工确认。

## 技术约束

- React PC 前端。
- Java 17 Spring Boot 单体后端。
- MySQL 与 MongoDB。
- Selenium Chrome 仅用于券商登录。
- Docker Compose 统一部署。
- 不增加非核心基础组件或独立业务服务。

## 安全要求

- 默认 `LIVE_MANUAL`。
- 默认 `TRADING_REAL_WRITE_ENABLED=false`。
- 数据、模型或券商状态异常时禁止新开仓。
- 前端不得以固定示例数据替代真实接口结果。
